# Домашняя финалка

Калькулятор стеков, выигрышей и расчётов для домашнего покерного турнира.
Один HTML-файл, без сборки и зависимостей: открыл `index.html` — работает,
в том числе с телефона и без интернета (шрифты подгружаются из сети, без них
просто подставятся системные).

## Что умеет

- **Банк** — бай-ин × количество бай-инов у каждого игрока (ребаи — плюсиком).
- **Стеки** — вручную или счётчиком фишек по номиналам (25 / 100 / 500 / 1000,
  номиналы редактируются, до шести штук).
- **Два способа делить банк**
  - *по стекам* — каждый забирает долю банка пропорционально своим фишкам;
  - *по местам* — призовые проценты (по умолчанию 50 / 30 / 20), места
    добавляются и убираются, кривая сумма процентов нормализуется.
- **Общий набор фишек** — стоимость делится поровну на всех, тому кто оплатил,
  возвращается разница. Отключается тумблером.
- **Итог каждого** = выплата − его взносы − доля за набор (+ стоимость набора,
  если платил он). Округляется до рубля так, что сумма всех итогов остаётся нулём.
- **Кто кому платит** — минимальное число переводов, чтобы закрыть все долги,
  плюс кнопка «Скопировать» — отправить расклад в чат.
- Расклад сохраняется в localStorage: закрыл вкладку — вернулся на то же место.

## Как считается

```
взнос_i    = бай-ины_i × бай-ин
банк       = Σ взнос_i
выплата_i  = банк × стек_i / Σ стек        (режим «по стекам»)
выплата_i  = банк × процент_места / Σ процентов  (режим «по местам»)
доля_i     = стоимость набора / число игроков
итог_i     = выплата_i − взнос_i − доля_i (+ стоимость набора, если платил он)
```

Пока стеки не введены, банк ещё никем не выигран — выплата каждому равна его
собственному взносу, поэтому в этот момент видно только расчёт за набор,
а деньги никуда не «пропадают». Инвариант `Σ итог_i = 0` держится всегда,
и до, и после округления.

Переводы считаются жадным алгоритмом: самый крупный должник гасит самого
крупного кредитора. Это даёт не больше `N − 1` переводов на `N` игроков.

## Тесты

`test/browser-test.js` гоняет приложение в настоящем Chromium через Playwright:
арифметика обоих режимов, расчёт за набор, счётчик фишек, добавление и удаление
игроков, сохранение между перезагрузками, крайние случаи, тёмная и светлая тема,
отсутствие горизонтальной прокрутки на 390px, плюс 400 случайных раскладов на
проверку того, что деньги не появляются и не пропадают.

```sh
npm i playwright-core
node test/browser-test.js              # системный Chromium
CHROME_PATH=/path/to/chrome node test/browser-test.js
```
