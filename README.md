# Домашняя финалка

Калькулятор для домашнего покера: считает стеки, делит банк и разводит долги
между друзьями. Один HTML-файл, без сборки и зависимостей: открыл `index.html` —
работает, в том числе с телефона и без интернета (шрифты подтягиваются из сети,
без них подставятся системные).

## Три формата игры

| Формат | Когда нужен | Как делится банк |
| --- | --- | --- |
| **Турнир по местам** | доиграли до победителя | по призовым процентам занятых мест |
| **Делим по стекам** | расходимся посреди игры | пропорционально фишкам на руках |
| **Кэш** | каждый закупается и выходит когда хочет | фишки меняются обратно по курсу закупки |

## Что умеет

- **Бай-ины и ребаи** — плюсиком у каждого игрока, банк пересчитывается сам.
- **Места** выставляются вручную, призовые проценты редактируются (по умолчанию
  50 / 30 / 20), места добавляются и убираются. Кривая сумма процентов
  нормализуется, одно место на двоих — приз делится между ними поровну.
- **Стеки** — вручную или счётчиком фишек по номиналам (25 / 100 / 500 / 1000,
  номиналы редактируются, до шести штук).
- **Кэш** — задаётся закупка (сколько рублей и сколько фишек за них), выход
  считается по курсу. Если фишки на руках не сходятся с закупками, приложение
  говорит об этом прямо, а не молча раскидывает разницу.
- **Общие расходы** — список трат вечера (набор фишек, пицца, вода): сумма и кто
  оплатил. Делятся поровну на всех и попадают в общий расчёт.
- **Итог каждого** = выплата − его взносы − доля расходов (+ то, что он оплатил).
  Округляется до рубля так, что сумма всех итогов остаётся нулём.
- **Кто кому платит** — минимальное число переводов, не больше `N − 1` на `N`
  игроков. Кнопка «Скопировать» собирает расклад текстом для чата.
- Всё сохраняется в localStorage: закрыл вкладку — вернулся на то же место.

## Как считается

```
взнос_i    = бай-ины_i × бай-ин
банк       = Σ взнос_i

выплата_i  = банк × процент(место_i) / Σ процентов занятых мест   // по местам
выплата_i  = банк × стек_i / Σ стек                               // по стекам
выплата_i  = фишки_i × (закупка ₽ / фишек за закупку)             // кэш

доля_i     = Σ расходов / число игроков
итог_i     = выплата_i − взнос_i − доля_i + (что оплатил сам)
```

Пока результат не введён (нет мест, нет стеков, никто не вышел), банк ещё никем
не выигран: выплата каждому равна его собственному взносу, поэтому виден только
расчёт расходов, а деньги никуда не «пропадают». В турнирных режимах инвариант
`Σ итог_i = 0` держится всегда — и до, и после округления. В кэше сумма итогов
равна расхождению фишек с закупками, и это расхождение показывается явно.

Переводы считаются жадным алгоритмом: самый крупный должник гасит самого
крупного кредитора.

## Тесты

`test/browser-test.js` гоняет приложение в настоящем Chromium через Playwright:
арифметика всех трёх режимов, призовые места и их крайние случаи, счётчик фишек,
расхождение фишек в кэше, общие расходы, добавление и удаление игроков,
сохранение между перезагрузками, миграция старых раскладов, тёмная и светлая
тема, отсутствие горизонтальной прокрутки на 390px — плюс 600 случайных
раскладов на проверку того, что деньги не появляются и не пропадают.

```sh
npm i playwright-core
node test/browser-test.js              # системный Chromium
CHROME_PATH=/path/to/chrome node test/browser-test.js
```
